# 一期范围与验收

## 产品

参考 Codex / ChatGPT 的工作台形式，不使用测试标识、模拟内容、装饰性标语或伪造的连接状态。

1. 创建、选择和继续会话；会话及公开内容持久化。
2. 选择或添加 Agent，选择该 Agent 实际支持的模型及模型参数。
3. 为会话选择本地项目。无项目时使用独立工作目录。
4. 每个参与者在右下角有一个 pet；加入、移除和运行状态与成员同步。
5. 导入 Codex pet 安装链接及本机已有 pet。个人导入的资源保存在本机，不提交到仓库。
6. 所有 Agent 可获得共同记录，每个参与者有独立 local_session。点击 pet 可查看该成员公开回复、公开推理摘要和工具活动。
7. 只有全部当前参与者明确接受同一份候选结果，或两位参与者在交流后明确保留彼此冲突的不可让步立场，才生成终局结果。
8. 超时、失败、暂停、人工停止、无效判断或预算耗尽不能伪装成共识。保留记录并提供继续讨论入口。
9. 不做会话 ACL 和自定义职责分配。
10. 使用标准化接入接口；支持原生 Codex、Cursor、Reasonix，以及通过 Agent Card 接入的 A2A Agent。

## 验收

- [ ] 会话切换及刷新后保留真实消息、项目、成员和配置。
- [ ] 模型列表与参数来自实际能力，修改配置真正传到原生 Agent。
- [ ] 本地项目浏览与选择可用，路径经验证。
- [ ] 至少三个不同原生 Agent 在同一会话中完成真实讨论并复用各自会话。
- [ ] 标准 A2A 接入经过协议级检查。
- [ ] pet 的数量、动画和详情与参与者同步；Codex 链接导入可用。
- [ ] 共识和分歧终局均有可复核的成员判断，不以多数票代替全体接受。
- [ ] 失败、取消与重启不会误报完成或混入其他会话。
- [ ] 桌面、窄屏、键盘操作和主要空态/错误态可用。
- [ ] 没有模拟运行路径或测试标识；真实账号与机密信息不进入源码。
- [ ] 构建、关键逻辑与 HTTP 集成检查通过，进度已提交 GitHub。
